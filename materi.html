Beranda Halaman
Pada halaman ini, kita akan membahas materi dasar HTML. HTML (HyperText Markup Language) adalah bahasa markup yang digunakan untuk membuat halaman web. Dengan HTML, kita dapat menyusun struktur konten, menambahkan teks, gambar, tautan, dan elemen lainnya ke dalam halaman web.

Struktur Dasar HTML

Struktur dasar HTML terdiri dari beberapa elemen penting, termasuk:

  • <!DOCTYPE html>: Mendefinisikan tipe dokumen HTML.
  • <html>: Elemen root yang membungkus seluruh konten halaman.
  • <head>: Bagian yang berisi informasi meta, judul halaman, dan tautan ke sumber daya eksternal.
  • <body>: Bagian yang berisi konten utama halaman web.

Tag dan Atribut

Tag HTML digunakan untuk menandai elemen-elemen dalam halaman web, sedangkan atribut memberikan informasi tambahan tentang elemen tersebut. Contoh tag HTML adalah <p> untuk paragraf, <a> untuk tautan, dan <img> untuk gambar. Atribut umum termasuk href untuk tautan dan src untuk gambar.

Membuat Halaman HTML

Untuk membuat halaman HTML, kita dapat menggunakan editor teks sederhana seperti Notepad atau editor kode seperti Visual Studio Code. Setelah menulis kode HTML, kita dapat menyimpan file dengan ekstensi .html dan membukanya di browser untuk melihat hasilnya.

Menguji Halaman pada Browser

Setelah membuat halaman HTML, kita dapat mengujinya dengan membuka file tersebut di browser web. Browser akan merender kode HTML dan menampilkan halaman sesuai dengan struktur dan konten yang telah kita buat. Jika ada kesalahan dalam kode, kita dapat memperbaikinya dan menyegarkan halaman untuk melihat perubahan.
